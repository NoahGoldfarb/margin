Ctrl-click anywhere on a page. The page opens at that exact line and a note starts there, in Markdown with LaTeX.

Keys

Ctrl-click
Split the page where you click and start a note there
Drag
Highlight that spot on the page; click a highlight to remove it
Tab
Expand a snippet, jump to the next $0 slot, or step out of }
tbl + Tab
Insert a table (tbl4x5 for 4 columns × 5 rows); Tab / Shift+Tab move between cells, Enter adds a row
/
In math, turn what you just typed (or selected) into a fraction
Esc
Leave the note and go back to the page (deletes it if empty)
Alt+↑ / Alt+↓
Jump to the previous or next note
LaTeX
Configure snippets such as mk and frac
Ctrl+Shift+⌫
Delete the note you are in
Cmd+⌫ / Ctrl+⌫
Delete the open file (a PDF takes its notes and recording with it)
Cmd+W / Ctrl+W
Close the tab — and the window once no tabs are left
Ctrl+Tab
Next tab (add Shift for the previous one)
Cmd+\ / Ctrl+\
Split the view in two — a textbook beside the lecture
Cmd+Alt+← / →
Move between the two halves
Cmd+1…9
Jump to a tab by position; 9 is the last one
Ctrl+O
Open a PDF
Ctrl+Shift+O
Open a folder in the sidebar
Ctrl+,
Settings — theme, accent color, note text size
Ctrl+F
Search filenames, PDF text, and notes across the open folder
Ctrl+= / Ctrl+- / Ctrl+0
Zoom in, out, reset to fit the page to the window
Ctrl+E
